# Security policy

This repository is an educational alpha and is not approved for production
remediation. Report vulnerabilities privately through GitHub's security advisory
interface for `mrinmoyece/aegis-framework-platform`; do not include credentials,
customer evidence, or exploit data in public issues.

Supported code is the latest commit on `master`. Layer 1 intentionally has no
credentialed model provider, production evidence source, approval mutation endpoint,
or effect implementation. See the [threat model](docs/threat-model.md) for control
assumptions and [limitations](docs/limitations.md) before adapting it.
