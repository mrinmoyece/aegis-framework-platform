# Changelog

All notable repository releases are recorded here. Versions describe repository
and bounded-local qualification; they are not production certification.

## [0.16.0] - 2026-08-18

### Added

- machine-validated 16-capability release-readiness and residual-risk manifests;
- a pinned, equivalent-axis custom-versus-framework comparison with explicit
  non-equivalence and missing-data labels;
- per-framework adoption, containment, rejection, and exit verdicts;
- a start-to-expert learning path, ADR index, governance policy, version policy,
  release checklist, contribution guide, and issue forms;
- executable cross-layer ownership, framework-loss, bypass, and rebuild checks.

### Changed

- Layer 16 release/governance validation now runs in local CI and GitHub CI;
- supply-chain scanning is scheduled and manually dispatchable;
- dependency update coverage, immutable pre-commit pins, CODEOWNERS routing,
  workflow bounds, waiver governance, and manifest/link checks are stricter;
- the package and operator workspace versions are synchronized at `0.16.0`.

### Security

- exact HIGH runtime waivers now require approval dates, compensating controls,
  no-fix confirmation, a seven-day expiry, and a new review for renewal;
- hard production gates remain open. No production certification is claimed.

## [0.15.0] - 2026-08-18

- Added bounded enterprise qualification, deterministic chaos and capacity
  profiles, readiness status, residual risks, and a pinned custom comparison.
